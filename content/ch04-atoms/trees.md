# Trees

```
THE ATOM
├─ Nucleus (tiny, dense, positive; almost all the mass)
│  ├─ Protons: positive; number = atomic number (Z); sets the element
│  └─ Neutrons: neutral; number = mass number (A) - Z; varies in isotopes
└─ Electrons (outside the nucleus; nearly massless)
   ├─ Neutral atom: electrons = protons
   ├─ Cation: lost electrons (positive)
   └─ Anion: gained electrons (negative)
```

```
THE PERIODIC TABLE
├─ Metals (left of the staircase, plus the inner transition rows)
│  ├─ Group 1: alkali metals (+1)
│  ├─ Group 2: alkaline earth metals (+2)
│  ├─ Groups 3-12: transition metals (variable charges)
│  └─ Inner transition metals: lanthanides (58-71), actinides (90-103)
├─ Metalloids (on the staircase): B, Si, Ge, As, Sb, Te
└─ Nonmetals (right of the staircase, plus H)
   ├─ Group 17: halogens (-1)
   └─ Group 18: noble gases (no ions)
```

```
IONS
├─ Monatomic ions (one atom)
│  ├─ Cations: metals lose electrons (Na⁺, Mg²⁺, Al³⁺)
│  └─ Anions: nonmetals gain electrons (Cl⁻, O²⁻, N³⁻)
└─ Polyatomic ions (a bonded group with a charge)
   ├─ Positive: ammonium NH₄⁺
   └─ Negative: nitrate NO₃⁻, sulfate SO₄²⁻, phosphate PO₄³⁻, ...
```
