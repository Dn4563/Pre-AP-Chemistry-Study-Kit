# Trees

One fenced block per hierarchy.

```
Matter
├─ Mixtures (variable composition; separated by physical methods)
│  ├─ Homogeneous (solutions): air, brass, salt water, gasoline
│  └─ Heterogeneous: oil-and-vinegar dressing, sand in water, jelly beans, soil
└─ Pure substances (fixed composition)
   ├─ Elements (one type of atom): Fe, Al, O₂, H₂, Au, Br₂, P₄
   └─ Compounds (two or more types of atoms; separated by chemical methods):
      H₂O, CO₂, C₁₂H₂₂O₁₁, NaHCO₃
```

```
Properties of matter
├─ Physical properties (observed without changing the substance)
│  ├─ Intensive (does not depend on amount): boiling point, color, density, luster, hardness
│  └─ Extensive (depends on amount): mass, volume, size, weight, length
└─ Chemical properties (ability to become a new substance): flammability, rusting, digestion
```

```
Changes in matter
├─ Physical change (same substance afterward)
│  ├─ Changes of state: melting, freezing, boiling
│  └─ Others: crushing, dissolving, tearing, distilling
└─ Chemical change = reaction (new substance afterward)
   ├─ Burning (combustion), rusting, fermenting, electrolysis
   └─ Indicators: precipitate, gas, color change, temperature change, light
```
