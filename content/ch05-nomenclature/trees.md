# Trees

```
NAMING DECISION TREE
Starts with H?
├─ Yes → Type V acid
│  ├─ no oxygen → hydro-…-ic acid
│  ├─ -ate ion → -ic acid (per-ate → per-ic)
│  └─ -ite ion → -ous acid (hypo-ite → hypo-ous)
└─ No → how many elements?
   ├─ More than two → Type IV (polyatomic ion)
   └─ Two
      ├─ Metal + nonmetal → ionic
      │  ├─ One-charge metal → Type I
      │  └─ Variable metal → Type II (Roman numeral)
      └─ Two nonmetals → Type III (prefixes)
```
